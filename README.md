# 🎯 Smart Attendance System using Face Recognition

An AI-powered Smart Attendance System that automatically marks student attendance using real-time face recognition.

---

## 🚀 Features

* 🎥 Real-time face recognition using webcam
* 🧠 Face encoding using FaceNet (DeepFace)
* 📊 Live dashboard with attendance metrics
* 📁 Automatic attendance storage in database
* 📈 Attendance tracking (Present / Absent)
* 🔄 Auto-refresh and real-time updates
* 📺 Live video feed integration
* 🧾 Excel & database logging
* 🎛️ Web-based control panel (React + Flask)

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS
* JavaScript

### Backend

* Python (Flask)
* OpenCV
* DeepFace (FaceNet model)
* SQLite
